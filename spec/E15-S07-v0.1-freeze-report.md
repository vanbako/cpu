## Freeze Decision

The CPU v0.1 architecture specification is ready to freeze as a coherent baseline for a first simulator, formal model, assembler subset, firmware ROM, kernel bring-up path, debugger, and RTL prototype.

The E15 consistency epic found and corrected blocking inconsistencies in numeric examples, reset/trap-entry wording, debug reporting, non-capability fault reporting, and LL/SC reservation clearing. The remaining open areas are explicitly deferred to platform profiles, implementation documentation, final opcode allocation, language ABI work, or post-v0.1 architecture stories.

No unresolved P0/P1 consistency issue remains in the audited v0.1 specification set.

## Accepted Deferrals

| Area | Classification | Freeze disposition |
| --- | --- | --- |
| Final numeric opcode bit assignments | Final opcode story | Not blocking. v0.1 freezes mandatory opcode coverage and placement constraints, not bit positions. |
| Exact object-file and binary-container serialization of 24-bit cells | Toolchain/container work | Not blocking. Any byte-oriented container must document cell serialization before interoperable tooling release. |
| Concrete C, Rust, or language-specific ABI details | Language ABI | Not blocking. E05 defines the architectural ABI substrate and mixed argument layout. |
| Trap-frame memory layout and context-switch save areas | OS/runtime ABI | Not blocking. The architecture defines the hardware saved level and slot-aware helpers. |
| Platform interrupt-controller claim, completion, thresholds, and external source identity | Platform profile | Not blocking. Core interrupt eligibility and reporting are frozen. |
| Platform start-event CSR numbers and mailbox addresses | Platform profile | Not blocking. E11-S03 freezes the logical mailbox and ordering contract. |
| Platform debug transport, authentication, and raw external memory access policy | Platform security/debug profile | Not blocking. Debug state transitions and tag-integrity constraints are frozen. |
| Trap-entry or interrupt-entry fatal escalation mechanism | Platform fatal/debug/reset profile | Not blocking. Recursive normal trap delivery through invalid vector state is forbidden. |
| Page-table walker bus-failure classification as `PAGE_FAULT` versus `ACCESS_FAULT` | Platform or later MMU story | Not blocking. v0.1 uses the E09-S07 default unless a platform story narrows it. |
| Cache-maintenance partial older-line progress after a later-line fault | Implementation documentation | Not blocking. Portable software cannot rely on recovery progress. |
| Remote TLB shootdown and remote instruction-cache synchronization mechanism | OS/platform protocol | Not blocking. The local architectural `SFENCE.VM` and `FENCE.I` requirements are frozen. |
| Coherent I/O, tag-aware DMA, IOMMU, and device capability authorization | Post-v0.1 architecture | Out of scope for mandatory v0.1. |
| Mandatory support for every extended performance event selector | Implementation capability with `WARL` discovery | Not blocking. Selector names and unsupported readback are frozen. |

## Freeze Boundary

The v0.1 freeze includes the architecture-level contracts in `agile-v0.1.md`, `design.md`, completed story artifacts in `spec/`, completed spike records in `spikes/`, and E15 review tools in `tools/`.

The freeze does not claim:

- Final binary opcode bit positions.
- A stable external object-file format.
- A complete language ABI.
- A concrete platform memory map or interrupt-controller register map.
- A complete OS trap-frame or context-switch ABI.
- Coherent/tag-aware I/O.
- User-mode access to extended performance counters.
- Mandatory support for every optional or `WARL`-discoverable implementation feature.

Those boundaries are intentional and do not block v0.1 specification freeze.
