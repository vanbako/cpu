# FPGA Smoke Program Corpus

Story: I26-S05

Status: Draft corpus with readiness markers

## Command

Validate the corpus:

```text
python tools\fpga_smoke_corpus.py --check
```

List cases:

```text
python tools\fpga_smoke_corpus.py --list
```

Inspect one case:

```text
python tools\fpga_smoke_corpus.py --case capability_memory.csc_clc_st48_ld48
```

## Scope

I26-S05 publishes the first FPGA smoke-program corpus. It binds generated BRAM
images and replay cases to expected LED, expected UART, and expected probe
signatures. The corpus is not a physical board pass claim. Board evidence still
depends on I24-S04 programming and I24-S05 first-board archive evidence.

Required gates:

- `python tools\fpga_bram_images.py --check`
- `python tools\fpga_replay_mapper.py --check`

I26-S04 remains blocked until I27-S02 provides the UART RX/MMIO path needed for
a board-safe loader. Until then, this corpus distinguishes image-ready cases
from replay-only or harness-required cases.

## Categories

| Category | Case | Program image status | Expected LED | Expected UART | Expected probe |
| --- | --- | --- | --- | --- | --- |
| `reset_pass` | `reset_pass.first_test_pause_stream` | Built into I23-S04 first-test ROM. | Heartbeat toggles, pass asserted, fail deasserted. | Pass flag, retire count at least 8, fault code zero. | Retire sequence reaches the pass threshold. |
| `scalar_control` | `scalar_control.call_return` | `call_return.direct_call_ret_fpga` is generated by I26-S02. | Pass only after a bounded control-flow harness completes. | Retire progress, no sampled fault. | PC leaves reset through CALL/RET fixture. |
| `capability_memory` | `capability_memory.csc_clc_st48_ld48` | `capability_memory.csc_clc_st48_ld48_fpga` is generated by I26-S02. | Pass with register setup; fail on tag/bounds/permission faults. | Fault code distinguishes capability/tag-memory failures. | Tag RAM starts clear, CSC writes a tag, ST48 clears it. |
| `trap_syscall` | `trap_syscall.sys_pause_iret` | `syscall_trap.sys_pause_iret_fpga` is generated by I26-S02. | Fail may assert until a trap-aware harness completes. | Trap cause or fault code identifies syscall trap. | EPCC/TVC path matches replay progression. |
| `translation_fault` | `translation_fault.mmu_tlb_page_fault` | Replay-only until an MMU page-table harness exists. | Fail asserted, pass deasserted. | Page-fault code and failed pass/fail state. | SATP/ASID/SFENCE state matches replay. |
| `failure_path` | `failure_path.divide_by_zero` | Replay-only until a fault-injection harness exists. | Fail asserted while heartbeat stays alive. | Divide-by-zero fault and preserved first mismatch. | No destination write after the precise scalar fault. |

## Handoff

Image-ready cases may be selected by I26-S03 rebuild evidence. Replay-only
cases remain corpus requirements and debug targets until their harnesses exist.
Physical closure requires a captured UART packet or GAO/ILA probe record, then
I25-S04 replay mapping and I25-S05 debug-evidence classification.
